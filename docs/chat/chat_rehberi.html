L0

Acemi — "Soru sorabiliyorum"

Hedef: Sohbeti açıp işe yarar cevap/çıktı almak.

Kazanımlar

  • Yeni sohbet aç, net soru sor
  • Dosya/görsel ekle (PDF, ekran görüntüsü)
  • Artifact'ı tanı (sağ panelde kod/doküman) — düzenlet
  • İyi istek = bağlam + hedef + format ("madde madde yaz")
İyi istek: "Şu hata mesajını çözmeme yardım et: [yapıştır]. Adım adım anlat." · Kötü: "kod çalışmıyor."
Oluşturma: Yok. Sadece soruyorsun. Kalıcılık L1'de Proje ile başlar.
Geçiş → L1: Aynı bağlamı her sohbette tekrar yapıştırmaktan sıkıldıysan Junior'sın.
L1

Junior — "Proje kuruyorum"

Hedef: Bağlamı kalıcı yapmak. Sohbet ortamının "hafıza" katmanı.

Kazanımlar

  • Proje oluştur — ilgili sohbetleri bir arada tut
  • Özel Talimatlar yaz (= kural): "Her zaman Türkçe yanıtla, kod örnekli"
  • Proje Bilgisi'ne dosya yükle (= kalıcı hafıza): şartname, stil kılavuzu, sözlük
  • Hafıza özelliğini kullan — Claude proje boyunca hatırlasın

Özel Talimat = sohbetin "kuralı"

# Proje → Özel Talimatlar kutusuna:
- Yanıtlar Türkçe, kısa ve madde madde.
- Kod örnekleri TypeScript, açıklamalı.
- Belirsizse varsayım yapma, sor.
Code'daki "kurala yaz" buna eşittir. Tekrarlanan talimatı Özel Talimatlar'a koy → her sohbette otomatik geçerli.
Proje Bilgisi: Sık atıf yaptığın doküman (API şeması, marka kılavuzu) → yükle. Her sohbette yeniden yapıştırma.
Geçiş → L2: Tekrarlayan bir işi (rapor/analiz reçetesi) standartlaştırmak istiyorsan Senior'sın.
L2

Senior — "Skill ve Connector üretiyorum"

Hedef: Tekrarlayan iş reçetesini Skill yapmak; dış kaynağı bağlamak.

Kazanımlar

  • Skill oluştur/yükle — tekrarlayan çok adımlı işin reçetesi
  • Connector bağla (Drive vb.) — Claude dış veriye erişsin
  • Özel Talimatları olgunlaştır (rol, ton, kısıt, format)
  • Artifact'larla iteratif çalış — sürüm sürüm geliştir

Skill nedir (Chat'te)?

Bir Skill = Claude'a verdiğin tekrar kullanılabilir uzmanlık paketi (talimat + örnek + opsiyonel kaynak). "Şu işi hep şöyle yap" mantığı. claude.ai'da Skills'i etkinleştirip kendi skill'ini ekleyebilirsin.

# Skill içeriği örneği (kavramsal):
Ad: haftalik-rapor
Ne yapar: Verilen ham veriden standart haftalık özet üretir.
Tetik: "haftalık rapor çıkar"
Adımlar: 1) metrikleri ayıkla 2) tabloya dök 3) 3 madde içgörü
Format: başlık + tablo + öneriler
Code farkı: Burada allowed-tools, model gibi teknik frontmatter yok. Skill daha çok "talimat + bilgi paketi". Agent/hook yine yok.
Geçiş → L3: Skill/talimatları bir ekiple paylaşmak istiyorsan Leader'sın.
L3

Leader — "Ekip standardı kuruyorum"

Hedef: Paylaşılan projeler + ortak talimat/skill standardı (Team/Enterprise).

Kazanımlar

  • Paylaşılan Proje — ekip aynı bağlam + talimatla çalışır
  • Ortak Özel Talimat standardı (ton, dil, gizlilik kuralları)
  • Skill paylaşımı / kütüphane — herkes aynı reçeteyi kullanır
  • Onboarding: yeni üyeye "şu projeye gir, talimatlar hazır"
  • Gizlilik yönetişimi: hassas veri Proje Bilgisi'ne girer mi, kuralı
Code'daki template/bootstrap'ın karşılığı: Burada "paylaşılan proje + ortak talimat seti" ekip standardıdır. Bir kez kur, ekip tutarlı çalışsın.
Governance: Talimat/skill eskir. Periyodik gözden geçir; geçersiz olanı sil — yanlış yönlendirme yapar.
Geçiş → L4: Otomasyon / API / programatik kullanım gerekiyorsa Plus'tasın.
L4

Plus — "Otomatikleştiriyorum"

Hedef: Sohbetin sınırını aşıp programatik/otomatik kullanım.

Kazanımlar

  • Connector ekosistemi — birden çok kaynak (dosya, takvim, e-posta) bağlı
  • API'ye geçiş — tekrarlayan işi Claude API ile otomatikleştir (prompt caching)
  • Skill + API birleşimi: ölçeklenir iş akışı
  • Ölçüm: hangi talimat/skill işe yarıyor, neyi sadeleştirmeli
Eşik kararı: Aynı sohbeti elle 20. kez yapıyorsan → bu artık bir API işi. Sohbet keşif/taslak içindir; tekrar otomasyon ister.
Gizlilik: API/Connector ile veri akışı genişler. Hassas veri nereye gidiyor, her zaman bil. Sır/kişisel veri için kurum politikasına uy.

API derinleşmek için: claude-api skill (Code tarafında).
