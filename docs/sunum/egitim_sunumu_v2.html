Bölüm 5 · Somut
Tek kelime: günaydın
Önce · ham

Claude: "Merhaba! Nasıl yardımcı olabilirim?"

→ Dünü bilmez. Sen baştan anlatırsın. 10 dk kayıp.

Sonra · yapı kurulu

Claude: "Dün giriş formu bitti. Bugün şifre sıfırlama (Faz 0). 3 uncommitted dosya. Başlayalım mı?"

→ session-start hook + handoff skill okudu.

"günaydın" sihirli değil. Arkada git + TODO Faz 0 + son günlük + özet — hepsi senin kurduğun yapı sayesinde.
