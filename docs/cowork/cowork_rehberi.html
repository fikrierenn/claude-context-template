Cowork nedir? Code ve Chat arasında nerede?

Cowork = ajan ortamı: sen görev verirsin, Claude araçlarıyla (Skills, MCP, plugin) izole bir alanda yürütür. Chat'ten güçlü (gerçek tool + dosya), Code'dan daha yönetilen/GUI.

Konumlama: İşleri otomatik yürütmek (araştır, düzenle, test et) ama terminal/hook ayrıntısına girmeden istiyorsan Cowork tam yeri. Her ajan kendi izole worktree'sinde çalışır — birbirini bozmaz.
Vurgu: Ajanların doğru işi doğru yapması (müşteri özeti, risk skoru, doğrulama) senin kurduğun/yazdırdığın Skills, bağladığın MCP connector'lar ve seçtiğin plugin'ler sayesinde. Cowork güçlü; ama o gücü yönlendiren senin eklediğin yapı. Hazır gelen değil — senin kurduğun.

L0

Acemi — "Görev verebiliyorum"

Hedef: Cowork'ü açıp bir işi yürüttürmek, sonucu görmek.

Kazanımlar

  • setup-cowork ile ilk kurulumu yap (plugin + araç bağlama)
  • Net görev ver: "şu klasördeki raporu özetle"
  • Claude'un adımlarını izle; onay isteyince oku → onayla
  • İzole worktree mantığını bil: deneme güvenli, ana dosyan korunur
Oluşturma: Henüz yok. Plugin/skill kurulu gelir; sen tetiklersin.
Cowork avantajı: Ajan birden çok adımı kendi yürütür (ara, oku, düzenle, test) — sen hedefi verip sonucu denetlersin.
Geçiş → L1: Görevleri rahat verdiysen, hangi skill/plugin'in ne yaptığını merak ediyorsan Junior'sın.
L1

Junior — "Plugin ve Skill kullanıyorum"

Hedef: Hazır yetenekleri (plugin, skill, connector) bilinçli kullanmak.

Kazanımlar

  • Rol-eşli plugin'leri tanı (geliştirici / analist / tasarım)
  • Skill tetikle: tetik ifadesini bilerek kullan
  • Connector bağla: Drive, takvim, e-posta, DB
  • Görev sonucunu onayla; gerekirse "şunu düzelt" ile iterasyon
Hafıza notu: Tekrarlayan talimatları görev tanımına / proje bağlamına yaz. Cowork'te de "yazılı olan yaşar" geçerli.
Geçiş → L2: "Kendi işime özel bir skill/connector olsa" diyorsan Senior'sın.
L2

Senior — "Skill / MCP üretiyorum"

Hedef: Kendi tekrar reçeteni Skill yapmak; kendi aracını MCP ile bağlamak.

Kazanımlar

  • Skill oluştur (tetik + adımlar + kısıt)
  • MCP connector ekle — kendi DB/API'ni tool olarak bağla
  • Görevi parçala: keşif → uygula → doğrula
  • Salt-okuma vs yazma sınırını gözet (denetim görevleri değiştirmesin)

En pratik yol: Claude'a yazdır

# Cowork'te:
Bana "musteri-ozet" skill'i oluştur. CRM connector'dan müşteri
çekip standart özet üretsin; "müşteri özeti çıkar" denince tetiklensin.
Code farkı: Cowork'te hook/derin git ayarı sınırlı; bunun yerine plugin + MCP + skill üçlüsüyle çalışırsın. Ağır git/hook disiplini gerekiyorsa Code'a geç.
MCP = yetenek genişletme: Bu repodaki sqlserver-mcp-server örnek — kendi veri kaynağını Claude'a tool yapar.
Geçiş → L3: Plugin/skill'i ekiple paylaşmak istiyorsan Leader'sın.
L3

Leader — "Ekip standardı kuruyorum"

Hedef: Ekip için ortak plugin/skill/connector seti + onboarding.

Kazanımlar

  • Rol bazlı plugin standardı (herkes doğru araçla başlasın)
  • Paylaşılan skill kütüphanesi + ortak görev şablonları
  • Connector erişim + gizlilik yönetişimi (kim neye bağlı)
  • Onboarding: yeni üye → setup-cowork + hazır skill seti
Code'daki bootstrap karşılığı: Cowork'te "rol-eşli plugin + paylaşılan skill seti" ekip standardıdır. Bir kez kur, ekip tutarlı.
Governance: Stale skill/connector = risk + zarar. Periyodik gözden geçir, gereksizi kaldır, erişimi denetle.
Geçiş → L4: Çok-ajan orkestrasyon / zamanlı otomasyon ihtiyacı doğduysa Plus'tasın.
L4

Plus — "Orkestrasyon ve otomasyon"

Hedef: Çok-ajanlı işleri orkestre etmek; zamanlı/otomatik akışlar.

Kazanımlar

  • Çok-ajan görev: paralel fan-out + adversarial verify
  • İzole worktree'lerle paralel değişiklik (çakışma yok)
  • MCP server'ları zincirle — birden çok kaynak tek akışta
  • Zamanlanmış/loop görevler (periyodik kontrol, rapor)
  • Meta: hangi skill/plugin değer üretiyor — ölç, sadeleştir
Plus zihniyeti: Tek görevi değil, görev üreten sistemi tasarlarsın. Doğrulama (verify) ve izolasyon birinci sınıf girdi.
Tuzak: Çok-ajan + MCP pahalı ve karmaşık. İhtiyaç kanıtlanmadan kurma; basit görev için tek ajan yeter.
